- **Delegates leave a project checkout on the branch they found.** A `delegate_to(project=…)` coder that checks out and pushes another branch in the board's shared base checkout is now switched back to the original branch when it's safe (clean tree, every commit already on a remote), and the change summary says which branch it left and that it switched back. When it can't switch safely — a dirty tree, unpushed commits, a concurrent delegation still holding the same checkout, or a git failure — the checkout is left untouched and the summary opens with a warning naming the root, both branches and the reason, so the lead can act instead of the board silently stranding.
