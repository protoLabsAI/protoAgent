- **Every skill is now always visible to the agent (#2867).** The
  always-on skills index listed only the 5 most-recently-used of an
  instance's skills — on a fresh install that hid the very behaviors the
  archetype shipped (an agent can't `load_skill` a name it has never
  seen). Now every discoverable skill is listed; a character budget
  (~2% of the model window) and `skills.top_k` decide which rows carry
  full summaries, and overflow rows keep their name and slash — matching
  how the rest of the AgentSkills ecosystem (Claude Code, Codex,
  OpenClaw) handles it. Also fixes the tier-union ordering so recency is
  honest across private and commons skills.
