- **Inbox items carry a display-only origin.** Inbox rows now record the chat session that caused them (`origin_session`) plus a small origin dict (`caller`, `caller_kind`, `on_behalf_of` only), stored alongside the existing `source`/`target_session` via the store's guarded migration. `InboxStore.add` takes `origin_session=`/`origin=`, `origin_for_context` maps a fired item's `job:` execution context back to its origin session, and `POST /api/inbox` accepts and returns the fields. Provenance only — origin never routes or authorizes delivery (ADR 0131 D2/P2a).
