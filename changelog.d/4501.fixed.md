- Workflow steps no longer refuse to start because earlier steps' output mentions a tool name. The #4327 dispatch scan read the interpolated prompt (finder reports, a PR diff, comments) as a request for the tool, so a PR that named `wait` or `github_get_pr` exhausted the review panel with no verdict (#4501). `sdk.run_subagent` takes `check_prompt_tools` (default `True`); the workflows engine passes `False`.
