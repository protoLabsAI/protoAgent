- **Fleet proxy: long member `/api/chat` turns go detach-and-poll instead of parking a 600 s socket (#4277).** A hub-proxied `POST /agents/<slug>/api/chat` without an explicit `detach` is now forwarded with `detach: true`; the hub polls the member's `GET …/turns/{turn_id}` every 2 s (each poll on the bounded read lane) until the turn is terminal or a 3600 s ceiling, then answers in the same shape a sync call returns — 200 `{response, messages, session_id}`, or the sync error status/detail for a failed/canceled turn. A turn longer than the old 600 s read cap no longer 504s (and that 504 no longer cancels the member turn on disconnect); the ceiling yields a 504 naming the turn id and a hub-side poll URL, leaving the member turn running. If the hub's own client disconnects mid-poll, polling stops and no cancel is sent. A member that answers 200 (an older core that ignores `detach`) is passed through unchanged, and an explicit `detach` is forwarded verbatim with no polling.
