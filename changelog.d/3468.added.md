- **The fleet deck: `protoagent fleet` with no arguments (#3468).** An interactive terminal over the running hub — every member with presence (the console's words: host, online, remote, stopped, unreachable), version skew, spend, and single-key start/stop/restart; a member detail screen with runtime status, a following log tail, the session inventory, and the telemetry rollup; a filter; `o` opens the member in the browser console. `protoagent top` is an alias. Textual is a core dependency, imported only when the deck opens, so `--help` and the non-interactive verbs stay fast; a build without it prints a one-line hint.
