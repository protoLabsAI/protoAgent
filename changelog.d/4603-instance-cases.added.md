- **Per-instance eval cases (#4603).** The eval runner now loads core `evals/tasks.json` plus the target instance's own `<config dir>/evals/cases.json` when that file exists, so a domain agent can carry its own eval suite without forking `evals/`. Instance case ids are namespaced `instance:<id>` (no collision with core ids), `--tasks instance:<id>` selects one, a malformed `cases.json` fails with an error naming the file, and `evals.sweep` / `scripts/evals_nightly.py` pick instance cases up through the runner. `evals.report` shows instance cases under their own heading, split by tier. Absent file → behaviour unchanged.
