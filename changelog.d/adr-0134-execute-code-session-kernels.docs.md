- **ADR 0134 proposes session-long execute_code state and opt-in MCP bridging.** A new Proposed decision record describes one long-lived kernel per session behind `execute_code.session_state` (off by default) so variables, imports and functions carry across a session's scripts, a bounded and visible kernel lifecycle, per-call policy binding that stays as strict as the direct path, operators bridging MCP tools by name (plus `mcp:<server>/*`) with `tools.help(name)` for on-demand signatures, and a two-lane benchmark gating the default-on decision. Documentation only — no runtime behaviour changes.
