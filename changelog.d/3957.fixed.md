- **Smoke follow-ups: honest telemetry, explicit model-override errors, and error statuses (#3957).**
  A per-turn model override that cannot be built (an unknown provider prefix, say) now fails
  the turn with an error naming the pick, on `/v1` (HTTP 400), the console and A2A, instead
  of silently running on the default model. `/api/subagents/run` and `/batch` answer a
  provider 429 as 429 (with `Retry-After`) and other upstream failures as 502, not 500.
  Telemetry rows name the requested model when no call reported one (failed and
  short-circuit turns), and `/<subagent>` and `/<workflow>` turns bill their model calls
  and tokens. `/goal` with an unknown verifier type says so instead of the safety refusal.
  The "goal paused — round cap reached" note is now in the transcript export. Deleting a
  chat with "forget" retires it first, so a failed retirement no longer loses its memory.
