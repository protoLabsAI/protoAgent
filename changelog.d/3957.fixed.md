- **Smoke follow-ups: honest telemetry, explicit model-override errors, and error statuses (#3957).**
  A per-turn model pick that cannot be used now fails the turn with a short error naming it,
  on `/v1`, the console and A2A, instead of silently running on the default model: an
  unknown connection prefix is a 400 on `/v1`, a known connection that could not be set up
  right now (a sign-in refresh, say) a 503. A pick now applies to its own turn only — a turn
  without one runs on the default rather than inheriting the previous turn's — and a goal
  keeps the pick it was set with. `/api/subagents/run` and `/batch` answer a provider 429
  as 429 (with `Retry-After`) and other upstream failures as 502, not 500. Telemetry rows
  name the requested model when no call reported one, and `/<subagent>` and `/<workflow>`
  turns bill their model calls and tokens. `/goal` with an unknown verifier type says so.
  The "goal paused — round cap reached" note is in the transcript export. Deleting a chat
  with "forget" hides its memory, retires it, then deletes exactly what it hid: a failed
  retirement loses nothing, and a harvest ticked alongside keeps everything it derives.
