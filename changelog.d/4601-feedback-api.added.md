- **Per-turn feedback API (#4601).** `POST /api/feedback` stores a thumbs up/down on one assistant turn and writes a `user_feedback` score onto that turn's Langfuse trace (ADR 0126 E2/D3); a second rating replaces the first, `value: null` un-rates and deletes the row, and incognito sessions are refused. `GET /api/feedback?session_id=` returns the session's per-turn trace_ids and current ratings so the console can map a rendered message back to its trace. Backend only — the thumbs buttons land in a follow-up.
