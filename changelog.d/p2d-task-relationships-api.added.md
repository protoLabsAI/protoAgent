- **Tasks API exposes request correlation and related conversations.** `GET /api/tasks/issues` rows now carry `rel_version` and decoded `request` / `requester` objects (`{}` when unknown), and `POST`/`PATCH /api/tasks/issues` accept related-conversation link objects (`{kind:"conversation", role, owner, context_id}`) alongside plain reference strings. A conversation link is accepted only when its `owner` is this agent and its `context_id` is one of this agent's own, non-server conversations; a forged owner, unknown context, server context, or another agent's context is rejected with 403 and nothing is written. `request`, `requester`, and `promotion_key` stay server-derived and cannot be set over the API. Part of Conversations in Work (ADR 0131, Phase 2 slice P2d).
