- **Reorder the fleet roster from Settings → Agents (#3197).** Every row in the fleet manager now carries explicit, accessible move-up / move-down controls. Activating one immediately reorders the roster and submits the complete immutable-id order to the merged hub API (`PUT /api/fleet/order`), then reconciles through the fleet query on success or error — no row or row action is lost, and an error rolls back to the server's authoritative order. Controls are keyboard-reachable with per-row accessible names, disabled at the list boundaries and while a reorder is in flight. Ordering is presentation-only: a member's name, URL, token, process state, and id are never touched.
