- **The external (ACP) runtime's system prompt now describes only the tools its bus actually exposes (#3248)**. It no longer carries the Subagent Delegation roster (`task` never rides the operator MCP bus) or capability doctrine for goal / tasks / schedule / watch tools that are not exposed — the bound set is read from the same allowlist the bus serves, at the first turn, never guessed. `ContextAssembler` gains `projects` and a lazily-resolved `bound_tool_names_factory` so any runtime can build an honest prefix; the ACP path passes no managed-projects section because the fenced filesystem tools never reach the bus.
