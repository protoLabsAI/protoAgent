- **Fleet Room member diagnostics drawer (#3169).** Open **Diagnostics** from any roster row
  to read that member's bounded, redacted log snapshot and inspect an exact A2A task by id —
  over the #3168 operator-authenticated, slug-scoped, read-only proxy endpoints, without leaving
  the console. The drawer is bound to the member you explicitly selected and keeps identifying it
  even as the active fleet selection changes. It renders actionable inline states for loading,
  empty/disabled buffers, stopped, unreachable, timeout, unauthorized, and missing-task reads,
  and surfaces the server's `note`, `truncated`, and `malformed` metadata rather than swallowing
  it. Live SSE log following is intentionally excluded — this is snapshot refresh only.
