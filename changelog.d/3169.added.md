- **Fleet Room diagnostics drawer — read a member's logs and inspect an exact task without leaving the console (#3169).**
  Every roster row in the ⌘⇧K Fleet Room now carries a Diagnostics action that opens a drawer
  bound to the member you clicked. It pulls that member's bounded, redacted log tail from
  `GET /agents/{slug}/api/diagnostics/logs` and inspects one exact A2A task by id through
  `GET /agents/{slug}/api/diagnostics/tasks/{task_id}` — the shipped #3168 contract, reached
  through the existing per-agent proxy so a local peer and a registered remote member work the
  same way.

  The inspected member is **drawer-local and pinned**: it stays authoritative across the fleet
  poll and every selection change, so the drawer keeps identifying the member you opened it on
  and never retargets to whoever the composer or the focused window points at (ADR 0042).

  Every failure mode resolves to an actionable inline state rather than a raw error or a blank
  panel: stopped (proxy 409), unreachable (502), timeout (504), unauthorized (401, surfaced
  without hijacking the hub token prompt), and missing task (404). Server-owned metadata is
  shown verbatim — a disabled/empty log buffer, a clamped `lines=` note, and a task response's
  `truncated`/`malformed` arrays. Snapshot-refresh only (an explicit Refresh); live SSE log
  following is deliberately out of scope, as is any browser handling of member credentials.
