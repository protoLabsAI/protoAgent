- **Each turn's telemetry row now records what triggered it.** The `turns` table gains an `origin` column: `scheduler`, `watch`, `inbox`, `webhook` and the other server-fired origins for an A2A turn, an empty string for a live operator chat turn, and the surface name (`v1`, `api-chat`, `plugin`, `local`) for a non-streaming turn. An existing telemetry database gains the column when it is next opened, and rows written before it read an empty origin. The telemetry CSV export gains the same column at the end. Nothing reads it yet: the spend cap that meters unattended turns from this table comes in a later change. Refs #5540 (ADR 0135 D12).
