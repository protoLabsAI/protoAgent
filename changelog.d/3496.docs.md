- **The fleet deck has its own guide, and member ports are documented as machine-wide (#3496).** `docs/guides/fleet-deck.md` walks through the deck task by task — reading the fleet, talking to a member, answering a turn that waits on you, managing members, every hub on the box, credentials, offline mode and troubleshooting. The Fleet and Operating-a-fleet guides link it and describe how `--port auto` now picks a port no instance on the machine records, a runbook covers port collisions between instances created before that check, ADR 0041 records it, and PROTO.md carries the deck's import and markup rules.
