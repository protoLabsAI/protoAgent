- **Continue in a new chat turns a read-only conversation into a real chat tab.** The **Continue in a new chat** button in the Conversations reader now opens and selects a fresh chat tab, leaves the Conversations stage so the new tab is actually shown, and pre-fills its composer with `About the conversation "<title>" (<origin>): ` plus a hidden `recall_session` reference to the original thread's context id — so the agent can pull the full transcript on demand. Nothing is sent and no toast fires: the opened, selected, pre-filled tab is the feedback — you edit the prompt and send. (docs/design/other-conversations.md §4.5, slice C4.)
