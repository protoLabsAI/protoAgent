- **Design mockups with a browser link.** The artifact plugin gains a `design-mockups` skill that teaches the agent to build a reviewable screen preview: real data, design-system components only, a toggle bar for theme, width and every UI state, and a built-in check that fails the render when anything spills past the frame at 1440 px or 390 px. `open_artifact` now opens any rendered artifact (html, React, markdown, mermaid, SVG, charts) as a full page in a new browser tab, not only saved files. The link is signed for that one version, expires after 30 minutes like the file link, and follows the browser's light or dark setting unless `?theme=light` or `?theme=dark` forces one.
