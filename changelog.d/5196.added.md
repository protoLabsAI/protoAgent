- **Durable live-sync change log (#5196, ADR 0130 S1).** Every retained event-bus publish now also lands in a per-instance append-only SQLite log of `(seq, kind, entity_id, ts)`, swept at 7 days / 100k rows. A client resuming `GET /api/events` via `Last-Event-ID` (or `?since=`) replays from that log — surviving ring eviction and server restarts — and a cursor older than retention gets a `resync_required` event instead of a silent gap. Progress frames stay live-only, as before.
