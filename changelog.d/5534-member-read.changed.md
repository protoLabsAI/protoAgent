- **Reading a fleet member's API goes through one shared helper.** The bounded, authenticated member read behind `/api/telemetry/fleet` and `/api/usage/fleet` moved from `operator_api.telemetry_routes` to `graph.fleet.member_read`, so hub tools can use the same read instead of a second copy. Nothing about the read changed: a local member still gets the fleet service token, a remote its stored bearer, and any failure reports the member unreachable. Code or tests that patched `telemetry_routes._fetch_member_json` should patch `graph.fleet.member_read._fetch_member_json`. Refs #5534.
