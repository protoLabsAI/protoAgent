- **Browser résumé uploads on Greenhouse verify, and parallel browser actions no longer cross-contaminate fields (#4237).** Greenhouse swaps the résumé input *and* its `<label for>` for a filename chip, so `browser_upload` reported "nothing is attached" and `browser_form_read` dropped `#resume` entirely. Upload now captures the field's surviving wrapper before the attach and verifies the chip there. Form read reports the vanished input under its id, with the filename as its value. Separately, every browser tool now holds a per-session lock, so parallel calls in one step (for example several `browser_fill`s) run one at a time in arrival order instead of interleaving keystrokes across fields.
