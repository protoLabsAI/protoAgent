- **An agent can no longer "cancel" a job a plugin owns.** `cancel_schedule` on a `plugin:<plugin_id>:…` job used to report "Canceled" while the owning plugin re-created the job on its next register, so the job kept firing and the agent told the operator it was gone. The tool now refuses with an error naming the plugin and pointing to that plugin's config section in Settings, where the cadence really changes, and `list_schedules` marks those rows `(plugin-owned: <plugin_id>)`. Agent-created jobs cancel as before. Refs #5313.
