- **Every keyboard shortcut is now a ⌘K command.** The command palette lists nine of the console's keyboard actions — New chat, Clear conversation, Focus chat composer, Next/Previous chat tab, Toggle latest tool block, and the left/right/bottom dock toggles — so you can run them by name instead of remembering a chord. Each row shows the shortcut it is bound to *right now*, so rebinding one in Settings ▸ Keyboard re-labels the row instead of leaving a stale hint, and the Settings command advertises ⌘, the same way. Chat-scoped actions open the chat surface before they run, so picking one from anywhere in the app does what you meant. (#3295)
