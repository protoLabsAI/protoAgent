- **Artifact shell uses DS embed layer for frame token injection (#577).** Replaces the hand-written `THEME_TOKENS` list and manual declaration concatenation in `shell.js` with the design system's `themeTokenSnapshot` / `snapshotToCss` pair (vendored as `pl-design-embed.mjs`, loaded alongside `pl-design-vega.mjs`). Every `--pl-*` token value that crosses into a sandboxed artifact frame now passes through `snapshotToCss`'s injection guard (values containing `<`, `{`, `}`, or `;` are dropped). If the embed module fails to load, artifacts degrade to no injected tokens rather than throwing.
