- **Opening a conversation in the Conversations tab reads the whole thread, read-only.** Clicking a row in the Conversations tab now opens the thread in the same pane, with the tab still selected: a header band (**← Back to list**, "Conversation · read-only", the title as a focused `h2`, a Running / Needs you / Failed badge and the origin line) over the thread's turns, each message labelled with its speaker — the caller ("Claude Code for Josh") and the agent — and a `TypingIndicator` on the last message while the thread is running. There is no composer; its slot holds a read-only note — "You can't type here. Replies go to a new chat, so the caller isn't interrupted." — with **Continue in a new chat** and **Copy link** (`#/conversations/<id>`). A thread waiting on you shows a warning callout with **Answer in Needs you**; a swept thread shows "This conversation is no longer stored."; a failed load shows a retryable error. The tab remembers the open thread across tab switches, and **Back to list** returns focus to the row it came from. (docs/design/other-conversations.md §3.4, slice C3.)
