- **ADR 0128 records the plan for per-role generation profiles.** Today every model call in an agent may emit up to 32k tokens with thinking on. A fleet audit found that 1.5% of calls produce 25% of output tokens, and 94 of the largest returned nothing. The ADR gives each subagent role a named profile (`routing`, `judgement`, `default`) with its own output, reasoning and context budget. A blank reply that hits the cap counts as a failed turn and is retried with a smaller budget. Core ships the names; operators set the numbers, and nothing changes until they do.
