- **Fleet members started by the hub get `run_command` by default.** The hub starts each member with `--ui none`, and that tier turned `filesystem.allow_run` off because a headless agent has nobody to answer the approval prompt. A hub member does: you answer its approvals in the hub console. The hub now sets `PROTOAGENT_FLEET_MEMBER=1` on every member it spawns, and with that marker the default is on. Each `run_command` call still asks for approval, an explicit `filesystem.allow_run` in the member's config still wins, and a plain headless instance still defaults to off. Restart a member for it to take effect. Refs #5322.
