- **Seven tests that failed at random in CI now pass reliably.** Some timed things on the real clock, which a slow CI machine can stretch. Others counted calls that other threads made. The private-turn stall test and the duplicate-message test now use a clock the test steps by hand. The delegate collection test now waits for the delegate's run to finish. The recurring-job restart test no longer fires an extra run when it crosses a minute boundary. The goal-store retry test and the subagent client test now count only their own calls, not calls from threads that earlier tests left running. The digest test no longer tries to create a file name with a colon, which Windows forbids. The duplicate-message tracker now accepts a clock from its caller. It still behaves the same.
