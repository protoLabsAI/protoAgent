- **The end-to-end mock server no longer dies when a browser closes a page with a request still being sent.** WebKit closing or reloading a page aborted the console's in-flight `POST /api/chat/presence`; the mock server's handler rejected, nothing caught it, and the node process exited, so every later test failed with "Connection refused" on 127.0.0.1:4319. A failing request handler now answers 500 and is logged with its method and path while the server keeps serving, the mock answers the presence report like the real route (204, or 400 when malformed), and if the server process does exit mid-run a supervisor reports the exit code or signal and its last error and the run fails naming it. Refs #5712.
