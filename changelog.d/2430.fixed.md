- **Windows uninstall no longer strands a ~128 MB `_MEI` extraction tree (#2430).** The
  installer hooks force-killed the onefile sidecar, killing the PyInstaller bootloader
  before it could sweep its `%TEMP%` extraction dir. Uninstall/reinstall now close the
  desktop shell gracefully first — the sidecar's parent-death watchdog exits the server
  cleanly and the bootloader removes its own residue — with the force-kill kept as a
  bounded fallback.
