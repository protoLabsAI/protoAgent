- **Every way a task closes now gets the same self-improvement review, once per completion.** With self-improvement on, closing a task queues a review of the finished work. Only `task_close` and the console's close button did that. A task that closed because its linked card, PR, job or directive finished got no review, and neither did one closed through `task_update`. Re-closing a task that was already closed could also queue a second review once the first had run. Now the task store marks the moment a task actually goes from open to closed, and the review is queued from that, whichever way the task closed. The review runs in the task's own session. Closing an already-closed task queues nothing; reopening a task and closing it again counts as a new completion. Directive auto-fulfil also now sees a task closed through `task_update` as closed. Nothing changes when self-improvement is off.
