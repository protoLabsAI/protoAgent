- **A task that closes on its own now gets the same self-improvement review as one closed by hand.** With self-improvement on, closing a task queues a review of the finished work. That happened when the agent called `task_close` or the operator closed the task in the console, but not when the task closed automatically because the card, PR, scheduled job or directive it links had finished. Those auto-closes now queue the same review, in the task's own session. A task is still reviewed at most once, however it closed. Nothing changes when self-improvement is off.
