- **Private steering tells the model its private notes are confidential.** A private steer and its replies stay in the conversation's context so the steering keeps working, but nothing marked them as private, so a later ordinary turn could quote them back to someone else. Each private message now reaches the model prefixed with a short operator note asking it to act on the message and never quote, paraphrase or reveal it. This is best effort: the label only changes what the model sees, nothing is removed from the conversation, the stored transcript is unchanged, and there is no output filter. Refs #5522.
