- **Local system notes can render a structured component card.** A role-"system" chat message carrying a `component` (the same component-v1 shape the agent's inline cards use) now renders through the chat component registry as a neutral in-thread card instead of the toned `.chat-note` markdown alert — so slash-command output can sit in the thread like the cards an agent turn emits. The message's `content` stays the plain-markdown fallback for export, copy and search, and a malformed `component` degrades to today's note rendering.
