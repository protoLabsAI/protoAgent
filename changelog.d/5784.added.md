- **`run_command` compacts long output from a successful command.** When a command exits 0 and its output is longer than `filesystem.compact_command_output_threshold`, the agent now sees the output with ANSI codes stripped, progress redraws resolved, repeated lines collapsed and the middle trimmed to a head and tail, and the full original output is saved to a spill file the marker names. A failing command, short output, or `filesystem.compact_command_output: false` returns exactly what it did before, and a failed spill write falls back to the uncompacted output. Fixes #5784.
