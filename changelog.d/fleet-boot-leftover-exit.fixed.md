- **A hub relaunch no longer reports the previous run's members as crashed.** A member record left in `fleet.json` by an earlier hub run (for example across an app update) is now dropped as a boot leftover by the supervisor's single dead-record helper, whichever reader sees it first, so `fleet.health` writes no unexpected-exit record, pages nothing and restarts nothing for it. Hub shutdown also clears already-dead member records, preserving unexpected-exit evidence for current-run crashes instead of silently discarding it. A member that dies while the current hub runs is recorded, paged and restarted as before. Refs #5584.
