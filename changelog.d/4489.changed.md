- **One save model per plugin settings tab (#4489).** A plugin Configure tab is now either save-then-apply or live — never both. A path-backed tab, or a schema tab the manifest marks `apply: live`, hides Save & apply and saves each field on change with an inline "Saved"; tabs without `apply:` keep today's Save & apply. Restart-only changes are no longer badged per field — after a save they collect into one banner ("N changes take effect after a restart") per plugin pane, which a plugin page can add to via a `protoagent:settings:restart-pending` frame message and which holds a slot for a Restart now action.
