- **Owner notices are written into Home's own thread.** With the `home_conversation` developer flag on, each notify, question and review notice is also appended to the Home conversation's thread as one reference message (`graph.home_entries.write_home_entry`), so a reply in Home has the brief or alert in context and the browser is not the only copy. The entry carries `kind`, `importance`, `source` and `notice_id`, and writing it never starts a turn. A decision raised by unattended work gets a short pointer entry; one raised in an operator chat gets none. During quiet hours the entry is written at once and only adapter delivery is held. Refs #5545 (ADR 0135 D9).
