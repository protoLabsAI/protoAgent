- **Store who started each A2A thread (#5283).** The first turn of an A2A context now persists the display-only origin its request metadata carries — `caller` (display name), `caller_kind` (`person`/`agent`), `on_behalf_of` (a person's name) and `title` (one line, clipped to 80 chars) — on that turn in the task store, so the forthcoming Conversations list can label the thread "From Claude Code for Josh". Later turns never overwrite it, an unrecognised `caller_kind` is dropped, and a private (incognito or hidden) turn stores nothing. These fields are display only and never an authorization input. On the sending side, `delegate_to` stamps `caller_kind: "agent"` on its outgoing provenance (a delegation is always agent-to-agent) and sends its `summary` as the thread `title` when non-empty, at both the request and message level. (docs/design/other-conversations.md §8, slice S1.)
