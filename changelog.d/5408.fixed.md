- **The desktop app signs itself back in without leaving panels broken or reopening the sign-in prompt.** When the console's stored token went bad, the desktop app quietly signed in again with its own token. But panels that had failed stayed failed until you reopened them, and requests still in flight with the old token reopened the sign-in prompt anyway. Now every panel reloads with the new token, and a rejection for a token that has already been replaced no longer brings the prompt back (#5408).
