- **Each instance now has one Home chat with a stable id, behind the `home_conversation` developer flag.** `GET /api/home` returns `{session_id, last_read_at}` and `POST /api/home/read` marks Home read; both answer 404 while the flag is off, which is the default. The id is generated once, stored in instance state and shaped `chat-home-…`, so Home is listed, retained, compacted and harvested like any other operator chat. Refs #5545 (ADR 0135 D9, ADR 0129 D6 amendment).
