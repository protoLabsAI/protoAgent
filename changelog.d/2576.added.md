- **Pick any signed-in provider's model straight from the chat.** The composer's model
  menu and `/model` used to offer only the configured provider's models; they now span
  every lane you're signed in to, so you can put this tab on Claude while the agent's
  default stays on the gateway. Cards read as plain model names with the account on a
  badge — the routing prefix stays behind the scenes, so favorites pinned from different
  providers sit in one list without looking like config syntax. `/model claude-sonnet-5`
  finds the right one without you typing the prefix.
