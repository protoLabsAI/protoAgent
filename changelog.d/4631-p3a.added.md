- **Memory supersession on save (#4631).** A `memory_save` with a `subject` now retires the live memories on the same subject, kind and scope (case- and whitespace-folded), stamping each with `superseded_by` so only the newest stays deliverable — superseded rows are kept for audit, readable via `get` and `memory_search`/`memory_list` with `include_superseded`. The save result names what it replaced and lists the other live rows on that subject, and a new `POST /api/memory/memories/{id}/revert` lets an operator undo a wrong supersession from the Memory inspector (404 when the row isn't superseded).
