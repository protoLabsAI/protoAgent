- **Memory supersession on save (#4631).** A `memory_save` with a `subject` retires matching pending agent/extracted memories on the same subject, kind and scope (subject matching folds case and whitespace), and reports replaced rows and other live rows. Pending saves preserve operator-authored, confirmed and always-on memories; replacing these requires a confirmed write. Superseded rows remain readable through `MemoryStore.get`, `MemoryStore.list(include_superseded=True)` and `memory_search(include_superseded=True)`. The new operator API endpoint `POST /api/memory/memories/{id}/revert` swaps an eligible superseded row with its live direct replacement, returning 404 for unsafe or unavailable pairs; inspector UI integration is not included.
