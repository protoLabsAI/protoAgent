- **Shell reads are no longer friction, and an agent with an unapproved shell can browse with it.** The friction plugin stops logging `cat`, `head`, `grep`, `rg`, `ls` and `find` through `run_command` as duplicates of a first-class tool. Those rows were a third of the fleet's ledgers on 2026-11-26 and all resolved as model behavior. Shell writes (`sed -i`, `tee`, `> file`) are still logged, since they skip `edit_file`'s lock and the code pane. The new `filesystem.shell_first` setting (off by default) hides `list_dir`, `find_files` and `search_files` from the lead model when `run_command` runs without approval, so the agent uses `ls`, `find` and `rg` and the three schemas leave its prompt. `read_file`, `edit_file` and `write_file` stay, and subagents keep every read tool.
