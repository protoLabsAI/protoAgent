- **execute_code session kernels bind policy to the running call.** A bridged tool call in a long-lived session kernel is now checked against the execute_code call running right now: each call opens a per-kernel active-call slot (its session_id, subagent fence and enforcement gate) on entry and clears it on exit — including on a timeout, a script exception or a cancel. A bridged call that arrives while no call is active (for example from a thread a previous script left behind) is refused with `Blocked by policy: no execute_code call is active` and recorded as a failed `ptc:` audit row under the kernel's session, without running the tool — so the bridge stays no softer than the direct tool path. Implements ADR 0134 D3.
