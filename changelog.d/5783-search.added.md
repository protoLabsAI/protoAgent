- **web_search can use Tavily, Firecrawl or SearXNG.** Set `web.search_provider` to `tavily`, `firecrawl` or `searxng` to send searches to that provider; keys come only from the `TAVILY_API_KEY` / `FIRECRAWL_API_KEY` env vars and SearXNG uses `web.searxng_url`. If the configured provider fails (missing key, HTTP error, unreachable), `web_search` falls back to DuckDuckGo and says DuckDuckGo answered; if both fail it returns an `Error:` naming the provider, so a failed search never reads as an empty result. The default `duckduckgo` setting behaves exactly as before. Refs #5783.
