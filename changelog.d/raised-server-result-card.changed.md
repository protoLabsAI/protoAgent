- **Server-initiated results in chat use the raised scheduled card.** A settled scheduled fire, watch reaction, inbox or webhook trigger, delegated task or background task now renders in the same raised card other scheduled results use (calendar/clock head, collapsed by default, expanding in place to the full markdown and the turn's tool calls) instead of the older dark result card, which is removed along with its CSS. A self-improvement review (a fire whose job id starts `self-improvement-`) is titled "Self-improvement review" rather than "Scheduled task". Goal runs, wait resumes, background-report replies and delegate results still render full-size. Refs #3028, #2990.
