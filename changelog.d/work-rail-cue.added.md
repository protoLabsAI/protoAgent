- **The chat status rail's quiet line gains its text helpers (#5279).** `work/tone.ts` adds two pure functions behind the chat-status-rail-v2 "quiet line" (§1 D2): `nextTime()`, the future counterpart to `relTime()` ("at 21:30" today, "tomorrow at 14:00", "18 Nov at 09:00" later, same en-GB style and `{ text, tooltip }` shape), and `railCue(item, now)`, which returns the one age-or-next-time line per Work kind — "Set …" for a directive, "Started …" for a background job, "Step N of M" for an active goal, "Updated …" / `staleTaskMeta()` for an in-progress or blocked task, "Next …" (or "Paused") for a schedule or wait, "Since …" for a watch, "Added …" for an open or deferred task — and "" when the source has no usable timestamp. No UI change yet; the rail renders these in a follow-up slice.
