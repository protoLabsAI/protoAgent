- **Undo a goal or watch delete from the console (#4955).** `DELETE /api/goals/{session_id}` and `DELETE /api/watches/{watch_id}` now return an `undo_token`; `POST /api/undo/{token}` within a 10 s window restores the record through the store's own `set` — re-firing its `goal.changed`/`watch.changed` event, so every open console refreshes. Undo runs server-side, so the Work view's Undo toast still works after the originating tab is closed. A restored watch keeps its id, settings, and status; a goal cleared with `close_tasks=true` restores only the goal, not the tasks it closed. An expired, unknown, or already-used token is a 404.
