- **Fleet discovery now finds agents published on this machine's own tailnet address (#3562).**
  `protoagent fleet --all` (the deck's hub tree) and `GET /api/fleet/discover` missed every
  co-located agent bound to the host's tailnet IP alone — e.g. containers run with
  `-p 100.x.y.z:7871:7870`. The local scan probes only `127.0.0.1`, and the tailnet scan read
  only the `Peer` map of `tailscale status`, where the host itself never appears (it is under
  `Self`). The tailnet channel now probes `Self.TailscaleIPs` too; a hit that loopback answers
  under the same agent name is the same agent (bound to `0.0.0.0`) and is dropped, so a hub
  does not list itself twice.
