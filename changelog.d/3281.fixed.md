- **The docs said the command palette opens on ⌘K; it is ⌘⇧K (#3281).** Plain ⌘K has been chat
  **Clear conversation** since #2949, and the published docs never followed — ADR 0063's defaults
  table was not just stale but inverted, listing the two chords the wrong way round. Every chord
  claim across the ADRs, guides and reference now reads ⌘⇧K / Ctrl-Shift-K, and the places that
  used "⌘K" merely as a nickname for the palette now say "the command palette". Also corrected in
  the sweep: ADR 0057's dead "⌘K is free" premise for the desktop shortcut (the launcher is
  ⌥Space, and ⌘⇧P toggles the window), three stale source line references, and a
  plugin-view-bridge claim that `editable: true` suppresses the palette — it does not, because
  the binding opts into `allowInInput`.
