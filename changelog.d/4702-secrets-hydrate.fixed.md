- **Secrets manager restores your own env values, keeps var names out of logs, and reports its true status.** With `secrets_manager.override_env: true`, a key removed from the manager now restores the value you had set before the manager overrode it, instead of unsetting it until a restart. Removals log a count at INFO (names only at DEBUG, per ADR 0080 D7). A changed `secrets_manager.refresh_seconds` takes effect within seconds instead of after the old interval, and `GET /api/secrets/status` reports the cadence that actually runs (the 30s floor applied, with the raw value as `configured_refresh_seconds`). With the manager disabled, the status now says `enabled: false` / `connected: false` instead of the last successful fetch. Refs #4702.
