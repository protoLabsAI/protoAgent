- **Desktop: a turn that finished while you were away now shows its cards.** If you switched agents mid-turn and came back after it ended, the desktop app reattached silently and kept the half-drawn turn: its tool card showed, but the cards or other components it produced never rendered. A server rejection of the reattach now takes the same replay path as the browser, so the finished turn renders in full. A server rejection of a send is also reported instead of re-sent.
