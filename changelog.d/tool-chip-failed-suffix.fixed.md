- **Folded tool chip: only the "· N failed" suffix is red.** A chip such as "17 tools · 1 failed" used to colour its whole label red, which read as the entire block having failed. The count now stays muted and only the failed suffix (plus the ✕ status glyph) takes the error colour, on both the tool fold and the background-jobs chip. Adopts the design-system fix by bumping `@protolabsai/ui` and `@protolabsai/ui-css` to 0.74.1.
