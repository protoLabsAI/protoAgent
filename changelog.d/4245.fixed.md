- **`browser_select` no longer fails on Greenhouse "mark all that apply" questions or the phone Country picker (#4245).** For react-select multi-selects, the read-back counted every chip twice and added an empty trailing entry (`I don't wish to answer, I don't wish to answer, `), so a selection that had worked was reported as a mismatch. Each chip is now read once, and choosing an option counts as a match when it appears among the chips. Greenhouse's 2026 phone Country picker shows only a flag and "+1", so it read back as "+1". The country name is now taken from the flag's country code, so it reads back as "United States". A shared dial code still never confirms a country on its own, so US and Canada stay distinct.
