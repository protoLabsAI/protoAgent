- **Caller-kind proof for steering queues and derived readers.** Re-runs the steering-queue and derived-reader isolation scenarios for federation, fleet-service, paired-agent and enrolled-console identities, each resolved through production authentication. Durable queue staging and the private-task record admit only a human operator; the prior-session digest and the prompt read route follow the caller's principal (the federation peer is denied per ADR 0066); the in-memory queue, session gist and private-partition tracing strip private content at write, so their canary-absence holds for every caller. Tests only — no product code changes. Refs #5403.
