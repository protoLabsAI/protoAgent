- **A tapped notification reuses the console window that is already open.** When no window is on the notice's own page, the push worker now focuses any open console window (the focused one, else the first) and hands it the tap, instead of starting a second console beside it; it opens a new window only when no console is open or focus is refused. The tap trace names the window chosen. A console on an agent's page that receives a notice with no Home entry, no link and only the generic console route stays put rather than reloading. Refs #5664.
