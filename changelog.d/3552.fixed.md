- **A subagent that stops mid-loop is continued, not reported "completed" (#3552).** A model that narrated its next read and never made the call — or returned an empty turn — ended the agent loop exactly like one that finished, so the step read `completed` on a sentence of intent. On a live review panel that was 17% of `review-finder` steps, which put a four-lane panel's completion rate near 0.83⁴. `SubagentConfig.completion_marker` now declares what a finished answer contains; a run-ending turn without it is sent back to the model (at most twice, inside the `max_turns` budget), and a run that still ends without it is labelled `ended without its deliverable` instead of `completed`. Set on `review-finder` and `review-synthesizer`; a subagent with no marker is unchanged.
