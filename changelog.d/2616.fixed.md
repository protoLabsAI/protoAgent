- **`grouped_entries()` in the friction plugin now breaks last-seen ties by ledger position, not first-seen order (#2616).** A stable sort on `last_seen` alone fell back to dict-insertion order for two groups tied on an identical timestamp — the exact inverse of "newest first" for an append-only log. Windows' coarser clock resolution made ties the common case instead of a rare one, so `Windows tests (native)` was red on `main`. A regression test now pins the tie case directly (two records sharing one timestamp), independent of any platform's clock resolution.
