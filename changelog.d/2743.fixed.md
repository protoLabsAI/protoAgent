- **Two plugin changes at the same moment no longer silently drop one of them (#2743).**
  Installing, enabling/disabling, updating, syncing and uninstalling a plugin each read
  `plugins.enabled` from the live config, merged their change, and only then took the
  config write lock for the save. Two of them at once — two installs, an install racing a
  toggle, a bundle update racing an uninstall — both read the same list and the second
  save wrote the first one's change back out: a plugin ended up installed but never
  enabled, or an uninstalled one came back, with nothing saying so. The merge now runs
  inside the lock against the config the previous save committed, and the lock moved to
  the config layer so the uninstall's own edit of the file and a bundle install's config
  seeding take it too.
