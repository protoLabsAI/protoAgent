- **A fleet member's file links work for remote peers, and links handed to clients expire (#4269).**
  The hub forwards a member's signed `/agents/<slug>/media/<file>?sig=…` link without its own auth.
  This applies only to that exact shape: a GET with no percent-encoding, a plain store name, and only
  `sig`/`exp` in the query. The member verifies its own signature. Links in A2A file parts and `/v1`
  replies now expire (`media.remote_link_ttl_s`, default 7 days; `0` = permanent; expired → 403).
  Console links and links issued before this change stay permanent. Attachments now survive a HITL
  pause. A late background attach is dropped rather than lost silently. An overflow retry no longer
  attaches the same file twice, and the 16-file cap is atomic (#4258).
