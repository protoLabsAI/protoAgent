- **Answering an agent's form no longer posts raw JSON or doubles the reply after a reload (#4403).**
  Submitting a `request_user_input` form showed the resume payload (`{"plan":"C"}`) as your
  message; it now reads as what you picked (`Plan: Plan C`), while the agent still receives the
  structured answer. And because the answer continues the same task as a new turn, a reload used
  to write the agent's reply onto the question turn too, so it appeared twice — only the turn
  after your answer takes it now.
