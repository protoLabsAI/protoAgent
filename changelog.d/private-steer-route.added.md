- **Conversations in Work: the steer route can send a private steer.** `POST /api/chat/sessions/{id}/steer` accepts an optional `private: true`. With `private_steering.enabled` on and a human-operator credential (the shared bearer or a paired `device`), the text is stored only in the private partition, the turn carries an opaque reference, and the reply is folded back into the same private record. The request is refused with a fixed 4xx when the flag is off, when the caller is the fleet service token, an `agent` device, a federation peer, a legacy API key or an open instance, or when it carries images or `incognito`; a steer asked to be private is never sent as an ordinary one. An ordinary steer that arrives while a private turn runs now waits for its own turn instead of folding into the private one. The reply fold now runs before the turn's final frame, so it also happens under the A2A executor, which stops reading at that frame. Without `private: true`, and with the flag off (the default), steering is unchanged. No console UI. Refs F12 of the residual-risk review, ADR 0131.
