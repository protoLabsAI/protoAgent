- **Soft spend limit warns before unattended work pauses.** The spend cap gains `spend_cap.daily_cost_soft_limit` and `spend_cap.daily_token_soft_limit` (Settings > Spend cap; zero or unset sends nothing). When today's unattended spend first passes either one, the operator gets one notice that day through the shared notice seam, with a console link and the hard limits it is heading for. It reads the same daily meter as the hard limit and never refuses a turn. Refs #5540 (ADR 0135 D12).
