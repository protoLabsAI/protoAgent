- **Linked file artifacts (#4370).** `save_file_artifact(..., link=True)` now serves a document in place from a registered filesystem project instead of copying its bytes. A linked version stores only a fenced `(project, project-relative path)` reference plus a size/mtime/sha256 stamp — no blob — so the 25 MB `max_blob_kb` cap does not apply; a linked file has its own larger `max_linked_kb` cap (200 MB default, `ARTIFACT_MAX_LINKED_KB`). A path outside every project, or a symlink escaping one, is refused. Linked artifacts are read-only: no `artifact_id`, no revisions.
