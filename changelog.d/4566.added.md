- **Explore without a model (#4566).** A visitor with no plan, key or local model can now finish setup and look around: `finish_setup` skips the model probe when no connection is declared and the model name is blank, writes the config and SOUL, and marks setup complete. The reload leaves the graph uncompiled in this state (rather than crash building a client with no key), so the server stays up and serves the console. The runtime status the console polls gains an additive `model_configured` boolean — false in explore mode, flipping to true on the next poll once a model is saved in Settings ▸ Model, no restart.
