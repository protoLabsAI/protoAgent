- **Switch a registered project between read-only and read-write from the console.** Tools ▸ Filesystem ▸ Work folders now shows a "write" switch on each managed project, so you no longer hand-edit `projects:` to let coders build in a project or to lock it back down. Turning writes on asks you to confirm first; turning them off applies at once. The change is saved to your config and takes effect live. A failure shows under that project's row. The switches are disabled while explicit Work folders override the registry, and projects with `fs: false` have none. Refs protoLabsAI/projectBoard-plugin#783.
