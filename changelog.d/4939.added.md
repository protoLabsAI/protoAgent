- **Open an artifact in a browser tab from the panel.** The Artifact panel's toolbar has an **Open in browser** button for rendered artifacts (HTML, React, Markdown, Mermaid, SVG, Vega-Lite). It opens the version on screen as a standalone page in a new tab, or in your system browser on the desktop app. The link expires after 30 minutes, the same as the one the agent hands out (#4939).
