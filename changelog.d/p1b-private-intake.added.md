- **Private intake for idle and parked steering.** A private steer is now recorded — with its deduplication key — into the private partition before any turn starts; the loopback self-POST carries only an opaque, delegation-bound reference — never the text — and the trusted runner resolves it fail-closed before the turn runs. An idle session starts a fresh turn and a parked one rides the guarded resume path on the original checkpoint binding; a retried steer reuses the one record (never a second shell or a second turn), a peer-owned task stays the peer's with no private prompt in its requires-input message, and a missing record, version or binding stops the turn with no ordinary SendMessage fallback. A metadata-less turn clears earlier resolver inputs so idle checks still detect its parked interrupt under a custom resolver. The mechanism stays dormant and is exercised only by tests. Refs #5401.
