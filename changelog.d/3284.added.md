- **The console's ⌘K fork seam now carries presentation, render-time gating, and dynamic sources (#3284).**
  A `registerPaletteCommand` entry can supply an `icon`, a `hint`, a display-only `shortcut`
  string, and `disabled` + `disabledReason` so a row that can't run stays discoverable and says
  why. A new `when(ctx)` gate is evaluated on every render rather than once at registration, so a
  flag that hasn't loaded yet — developer flags fail closed while `/api/flags` is in flight — no
  longer hides a command permanently. `registerPaletteSource` contributes rows computed at read
  time for live data, registration is last-wins by id and returns an unregister function, and
  `subscribePaletteCommands` / `paletteCommandsVersion` let a consumer pick up a command
  registered after its first render.
