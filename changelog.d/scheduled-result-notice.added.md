- **A scheduled result that posts a card to its chat now also notifies you on your chat surfaces.** When a scheduled run posts a result card to the chat that created it, the server sends one typed notice (kind `review`, importance fixed in code as `normal`) through `notify_chat_surfaces`, with the run's summary and a console link to that chat. The notice is sent from the same place the card is published, so a run that posts no card (an empty answer, a `NO_UPDATE` reply, a repeat of the last delivered result, or a chat idle for over 24 hours) sends no notice either. Refs #5537 (ADR 0135 D8, D11).
