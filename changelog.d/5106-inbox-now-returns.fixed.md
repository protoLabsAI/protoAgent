- **`POST /api/inbox` with `priority: "now"` answers as soon as the turn is accepted (#5106).** The Activity turn it fires is asked to return as soon as it is accepted, so the call no longer hangs while a running job holds the Activity thread; the queued turn still runs once, in the background, when the thread frees. A caller that retries should send a `dedup_key` so a retry is deduplicated rather than stored twice.
