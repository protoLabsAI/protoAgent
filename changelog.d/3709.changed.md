- **Console chat now waits for a session's transcript to load before anything edits it (#3709).**
  Every message change is a function of the current transcript, and each session carries a
  load state: changes to a transcript still being read are queued and applied once it
  loads, a failed read shows its edits as unsaved and retries, and nothing — saves, server
  hydration, reattach, the palette chat — can write over history that hasn't been read.
  Groundwork for moving transcripts to IndexedDB (ADR 0114).
