- **Streaming answers fade in word-by-word (#2769).** The console now enables
  streamdown's built-in animate plugin while a message is live: each arriving word
  fades in over 400ms with a 25ms cascade, so the ~24-char SSE chunks read as one
  continuous trickle instead of discrete text pops — the Perplexity-style reveal.
  Settled and history messages render exactly as before (the plugin leaves the
  pipeline entirely when a message isn't streaming), so nothing re-animates on tab
  switches and old transcripts carry zero animation overhead.
