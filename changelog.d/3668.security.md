- **A tokenless instance only answers host names it recognizes (#3668).** An open instance
  (no bearer, no X-API-Key, which is the desktop default on loopback) now applies a `Host`
  allowlist to every HTTP path and WebSocket, including the console, `/api`, `/a2a` and `/v1`.
  Allowed: IP literals, `localhost` and `*.localhost`, `*.ts.net`, this machine's `<name>.local`,
  a named bind, the hosts of `A2A_ALLOWED_ORIGINS`, and `PROTOAGENT_TRUSTED_HOSTS`. Anything
  else gets `403`, and a WebSocket is closed `1008`. It is the same check the fleet proxy
  already applied to remote members (#3662), now instance-wide. In open mode, requests with a
  body to `/a2a` and `/v1/*` must also send a JSON `Content-Type` (`415` otherwise). Token-gated
  instances are unchanged. If other containers call an open agent by its compose service name,
  add that name to `PROTOAGENT_TRUSTED_HOSTS`.
