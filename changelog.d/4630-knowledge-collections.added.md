- **Knowledge collections API (#4630).** Serve the knowledge base by collection (ADR 0125 P2 slice 6): a new `GET /api/knowledge/collections` lists each collection with its chunk count, distinct-source count and newest ingest time, and `GET /api/knowledge/search` gains a `?collection=` filter. Chunks with a null or empty `collection` group under the `knowledge_ingest` default (`general`), an unknown collection returns an empty list rather than a 404, conversation history is excluded, and agent memory never appears (it lives in the `memories` table). `KnowledgeStore` gains `list_collections()` plus an optional `collection` filter on `search`/`list_chunks` (threaded through the hybrid and layered stores), and the console gains typed `listCollections()` + a `collection` search option. Server + typed client only — the browser view is a separate card.
