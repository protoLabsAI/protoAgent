- **`task_update` warns when a task is set in progress with nothing driving it (#5282).** Moving a task to `in_progress` whose work nothing will ever bring the agent back to — no unresolved linked card/PR/job, no pending follow-up, watch, background job or running turn in its chat — now appends a one-line note to the success result ("nothing is driving this task … otherwise a stall reminder fires after 30 min"). It uses the same driver test as the stall sweep and the Work view (`tasks.stall.is_driven`), so the three never disagree. The update always succeeds; a driver check that can't read its live state stays silent and the warning is skipped. Driven tasks and other statuses are never warned (ADR 0129 S13 / D9 item 6).
