- **Dismiss stale fleet items from operator chat.** The hub can cancel a member’s pending decision or close a waiting task as dismissed through existing operator routes, with a required reason and an audit entry for every attempt. Task dismissal requires a waiting state, checked again atomically when closing so resumed work is preserved. Conditional closes notify the member only after the close succeeds, avoiding false dismissal notices when work resumes. Unattended and subagent turns are refused. Refs #5602.
