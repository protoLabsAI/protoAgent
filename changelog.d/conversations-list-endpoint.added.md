- **Conversations list endpoint (#5283).** `GET /api/conversations?group=&before=&limit=` lists the agent's A2A threads with someone other than the operator's own console chats — one row per context with its title, origin label ("From Claude Code for Josh", "Delegation from protoEngineer", …), `for_you`/`automated` group, status and turn count. Background jobs, the Activity thread, the command palette, the Fleet Room and incognito/hidden threads are never listed; rows order needs-you, then running, then newest, over a 7-day window that `before=` pages back.
