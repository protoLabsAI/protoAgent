- **orgChart resolves delegate tokens env-var-first again (#3287).** The v0.2 rebuild
  (#3286) inverted `_token_for`'s priority, so an entry carrying both `auth.credentialsEnv`
  and an inline `auth.token` used the stored (potentially stale) copy instead of the live
  env var — auth failures against peers that rotate tokens via the environment. The env var
  wins again, and an entry whose named env var is unset now falls back to the
  inline/overlaid token instead of resolving to nothing.
