- **A restart no longer looks idle while a board coder is working, and no longer looks like a coder crash.** `GET /api/restart/readiness` now counts live coding-agent (ACP) dispatches as busy ("1 coding-agent dispatch running"), and reports busy if that count cannot be read, so a plugin rollout or a `when_idle` stop waits for the coder. When the server's own shutdown (or a client close) stops an agent with a prompt still in flight, the failure reads "<name> agent stopped: host shutting down" and the `AcpError` carries `host_shutdown=True`, instead of "agent exited (exit code 0)" with an unrelated stderr line. Refs #5267.
