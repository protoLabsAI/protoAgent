- **Switching agents paints a loading splash on the first frame instead of a dark screen.** A switch is a full page load, so until the console bundle ran, `#root` was an empty div on the dark background — longest in the desktop webview, where the bundled assets are re-read each switch. `index.html` now renders a static splash (the same layout, colours and spinner as the app's boot gate, inline CSS only) that names the agent it's opening from the URL slug and a display name the fleet switcher cached; React's `createRoot` replaces it with no visible jump. The Google Fonts stylesheet no longer blocks first paint (it's applied by a script-inserted link, with the system stack as the `display=swap` fallback), and the boot path now records `performance.mark`s (`pa:boot:script-start`/`first-render`/`ready`) whose segment durations log once at debug level so a slow switch can be measured in the desktop.
