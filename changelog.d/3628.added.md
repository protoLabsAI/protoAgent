- **Mermaid and SVG artifacts are navigable, and mermaid diagrams can link to the code (#3628).**
  The Artifact panel's diagrams now zoom (wheel/pinch toward the cursor, double-click, `+ − 0 f`,
  a Fit/Reset toolbar) and pan (drag, arrows) — by moving the SVG's viewBox, so they stay sharp in
  the desktop app too. `show_artifact` / `update_artifact` / `rewrite_artifact` take `links`: node
  ids, `participant:<name>` and `msg:<n>` mapped to project code, validated like `show_code`, snapped
  to an exact code `anchor` so they land on the intended line, and stored with each version. Clicking a linked node or message opens that range in the code pane
  beside the diagram (else your editor, else the path is copied); a **Links (n)** list makes them
  keyboard-discoverable. Long diagrams in a narrow dock open at a readable
  zoom from the top, and the panel toolbar folds Edit/Download/Delete into a ⋯ menu when narrow. A new `diagramming-code` skill teaches grounded, small, code-linked
  diagrams. Artifact plugin 0.20.0.
