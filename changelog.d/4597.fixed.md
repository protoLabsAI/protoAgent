- **A migrated gateway keeps the SDK-default endpoint (#4597).** A pre-registry config with a null `model.api_base` (a bare `api_base:`) and a key now migrates into a `gateway` connection whose `base_url` stays `null` — the OpenAI SDK default endpoint it ran on before — instead of an empty URL that failed every call. An operator-declared connection with a blank endpoint still fails loudly, so a connection's key never reaches the SDK default unless the loader migrated it there.
