- **A migrated gateway keeps the SDK-default endpoint (#4597).** A pre-registry config with a null `model.api_base` (a bare `api_base:`) and a key now migrates into a `gateway` connection that still falls back to the OpenAI SDK default endpoint it ran on before, instead of an empty URL that failed every call. The fix survives a console write too: editing any connection now persists the migrated gateway pinned to exactly where its key already went (and keeps that key), rather than saving a blank, keyless entry that brought the bug back on the next reload. An operator-declared connection with a blank endpoint still fails loudly, so a connection's key never reaches the SDK default unless the loader migrated it there.
