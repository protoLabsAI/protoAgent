- **Scheduler, background and metrics SQLite stores no longer raise "database is locked" under in-process write contention (#5122).** Each now takes the shared `infra.sqlite_locks.file_lock(path)` around its write transactions, so a second same-process connection waiting on `BEGIN IMMEDIATE` queues on a blocking lock instead of losing SQLite's busy-handler poll to a holder that commits and re-begins at once. `metrics_store` drops its per-object lock for the per-file one, so two stores on one file serialize too; `busy_timeout` still covers other processes.
