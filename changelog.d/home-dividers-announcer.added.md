- **Home shows where each day starts and what is new.** The Home transcript now puts a plain "Today", "Yesterday" or dated line above the first entry of each day, and an "N new" line above the first entry newer than the last time Home was read; that line stays put while Home is open instead of vanishing the moment it is marked read. A screen reader hears "New in Home:" and the title once for each entry that arrives while Home is open, never for the operator's own messages, and the transcript itself is not a live region. The Home tab's unread count now uses the same rule as the "N new" line, so alert cards count too. Other chats render as before. Refs #5545.
