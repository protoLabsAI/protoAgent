- **ADR 0129 D9 records the design for waking a task nobody is driving (#5270).** The ADR adds a shared "is this task driven?" test (unresolved link, pending schedule/`wait`, active watch, running background job or turn in its session), a 5-minute stall check that nudges an undriven `in_progress` task and, after three reminders with no change, moves it to `waiting`, a planned Work-view "in progress · idle Nm" / "stalled" status, a `task_update` warning when a task is set `in_progress` with nothing behind it, and a follow-up backoff that stops a recurring job from re-reporting the same parked work while it waits on a human. This fragment documents the decision only; the behaviour is built by slices S11–S14.
