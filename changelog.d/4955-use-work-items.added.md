- **One data hook behind the Work view (#4955).** `useWorkItems()` folds the agent's eight work sources — decisions, goals, watches, tasks, schedules, background jobs, activity and directives — into one uniform `{ items, status, loadedAt, error, retry }` per source, with every row's status normalized through the shared `tone.ts` mappers. It refreshes live off the bus (each `goal.changed` / `watch.changed` / `task.changed` / `background.*` / `scheduler.changed` push invalidates only the source it names), falls back to a 60 s schedule poll until the first `scheduler.changed` proves the bus is wired, and isolates failures so one source going `error` (or `stale`, keeping its last rows after a failed refresh) never disturbs the others. Adds `undo(token)` and `setScheduleEnabled(id, enabled)` console clients for the Work view's server-side undo and pause/resume.
