- **Artifacts can be pinned so history eviction never drops them (#3456).** The artifact store keeps only the 20 most recently touched artifacts across the whole instance, so a long-lived one (a master resume, a reference doc) was silently evicted after enough unrelated renders, stranding any id recorded elsewhere. The new `pin_artifact(artifact_id, pinned=True)` tool exempts an artifact from that eviction; pins don't count toward **Artifacts kept**. A new **Pinned artifacts** setting (`max_pinned`, default 10, `0` disables) caps them, and a pin past the cap is refused rather than silently unpinning another. Pinned artifacts still trim to **Versions per artifact**, and `list_artifacts` / `get_artifact` show pinned state. The stored format change is additive: older stores load unchanged, and an older plugin reads a pinned store without error.
