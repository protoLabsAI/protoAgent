- **Plugin `registry.on()` subscriptions now actually fire, and don't pile up on reload (#4800).** A plugin that reacts to bus events with the documented `registry.on("topic.*", fn)` used to get nothing on desktop, where `register()` runs before the event bus is wired — the subscription was logged and dropped. It is now queued and delivered once the bus comes up, and each subscription's unsubscribe is owned by the registry so reloading or disabling a plugin tears its old handlers down instead of stacking another live copy with stale state.
