- **A decision the agent asks never pauses the chat.** `request_decision` always saves the question and ends the turn; its old pausing path is gone, so no chat or scheduled turn can be held behind a decision the agent asks. The answer reaches the agent as a later message. Decisions paused before the upgrade can still be answered and resume their turn. `decisions.never_block` stays in config but no longer has an effect. Fixes #5678.
