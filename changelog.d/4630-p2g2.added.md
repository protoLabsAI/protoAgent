- **Opted-in agents receive the shared operator profile (#4630).** ADR 0125 P2-G2 delivers and writes the host-shared operator profile. When `memory.shared_profile` is on, the per-turn projection joins the shared store's **confirmed** rows to the memory layer under their own "Operator profile (shared)" section, placed before "Always-on memory": `delivery="always"` rows render every turn and `delivery="retrieved"` rows are searched with the turn's query, both drawing on the memory budget slice (never knowledge's). A shared row is dropped for an agent whose own private memory already holds a live row on the same subject and kind (the private row wins; a null-subject row never collides), and pending shared rows never deliver. `memory_save` gains a `shared` argument (shown to the model only when the store is enabled): `memory_save(shared=True)` proposes a `profile`/`standing` row to the shared store as `provenance=agent`, `review_state=pending` — reaching no agent until the operator confirms it — while a non-profile kind or a disabled store returns a clear error. Injection-log rows tag a shared id `layer=memory`, `source=shared_profile`.
