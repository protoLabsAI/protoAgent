- **A local model at `http://localhost:…` now connects.** The setup wizard and model probe rejected `localhost` endpoints (Ollama, LM Studio, LiteLLM) with "api_base host is blocked by the egress guard", because `localhost` resolves to `::1` first and Python reports `::1` as a reserved address. Loopback is now checked before the reserved-range block, so `localhost` and `[::1]` work wherever loopback is allowed; link-local, cloud-metadata, multicast and unspecified addresses stay blocked.
