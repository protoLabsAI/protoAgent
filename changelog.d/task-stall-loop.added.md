- **Stalled tasks get nudged, then parked for you (ADR 0129 D9).** A 5-minute sweep finds an `in_progress` task that nothing is driving — no linked work running, no follow-up scheduled, no live turn — and queues one agent nudge per pass to act on it, link the work, schedule a follow-up, set it waiting, defer or close. After three unheeded nudges it stops nudging and parks the task `waiting` with an ask so it lands in your Needs-you queue. The sweep never pages the operator directly.
