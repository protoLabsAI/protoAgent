- **Instance-wide standing orders.** A directive can now be recorded as instance-wide (`record_directive(instance_wide=True)`, operator chat turns only): it renders under STANDING DIRECTIVES for every chat and every scheduled or watch turn, not just the chat it was given in. It lives in the existing directive store; `GET /api/directives` lists these, and `PATCH /api/directives/{id}?instance_wide=true` and `POST /api/directives/{id}/withdraw?instance_wide=true` edit and withdraw them. `/directives` lists and revokes them from any chat. Each scope has its own rendering allowance so instance orders cannot crowd out the chat’s directives. Refs #5542 (ADR 0135 D13).
