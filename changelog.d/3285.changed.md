- **The Settings section table moved into an import-light leaf module, so naming a settings section no longer drags the whole settings UI along (#3285).**
  `apps/web/src/settings/sections.ts` now holds the ids, labels, icon names, flag/`hostOnly` gates and group order; `SettingsSurface.tsx` keeps the panels and resolves each icon name to a statically-imported component. Importing anything from `SettingsSurface` pulled in 90 modules and ~817 KB of panel source — every settings panel plus 26 lucide icons — which is what the ⌘K palette and the desktop Launcher window would have paid to deep-link a section. The leaf costs 2 modules and 12.7 KB, and a test pins it that way, since CI has no bundle-size gate to catch the regression. Nothing renders differently: no section was added, removed, renamed, reordered or re-gated.
