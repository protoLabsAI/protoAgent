- **Keep a domain's tools inside the subagent that owns it with `tools.subagent_only` (ADR 0117, #4069).** Name tools there and the lead agent no longer has them: its model is never offered them, a call to one is blocked with a pointer to `task`, and neither `search_tools`, execute_code's bridge nor the operator MCP can surface them. Any subagent that allowlists them still gets them, in the foreground or in the background. The lead's prompt loses those schemas, and the domain's tool output stays in the subagent's context. `tools.disabled` still wins. The console's Tools list marks these "Subagents only". Agent self-config can no longer change a subagent's tool allowlist, since that list is a permission.
