- **Chats stay in step across devices without a reload.** A console left open — the desktop app all day — now picks up the turns you send from another device (your phone) when you come back to the window and about once a minute while it's visible; before, it only caught up on a reload. The session index also names each chat's newest turn, so a long-running chat that remembers turns the server has already cleared still notices one it's missing.
