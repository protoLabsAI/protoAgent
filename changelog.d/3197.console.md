- **Accessible fleet reorder controls (#3197).** Settings → Fleet now gives every roster member explicit move-up / move-down buttons — the guaranteed keyboard/screen-reader path for reordering the fleet. A move immediately shows the new order and submits the complete immutable-id permutation to `PUT /api/fleet/order`; the optimistic update cancels the 3-second poll, rolls back on error, and always re-syncs with the server so a rejected reorder can't leave a stale order. Controls carry directional accessible labels and disable at the list boundaries and while a save is in flight. Reordering is presentation-only — it never touches member names, urls, tokens, process state, ids, or the host/self action safeguards, and every existing per-row control is preserved. Drag-and-drop is deferred: the `@protolabsai/ui` design system has no reusable sortable/DnD primitive (only `AppShell`'s built-in rail reorder), so a component-gap request is filed rather than introducing a bespoke reusable DnD control or a new DnD dependency outside the lockfile/attribution workflow.
