- **Reorder the fleet roster in Settings → Agents (#3197).** Drag an eligible fleet row to a
  new position — or use the per-row move-up / move-down controls, the equivalent accessible
  non-pointer path (icon-only buttons carry accessible names and disable at the list
  boundaries and while a save is in flight). Reordering submits the complete, immutable
  member-id order to the hub's `PUT /api/fleet/order`, writes it optimistically so the row
  jumps immediately, and invalidates the polling fleet query on both success and failure so a
  rejected save rolls back and reconciles without losing a row. Existing row actions and the
  self/host safeguards are untouched, and no member name, URL, token, process state, or id
  changes. The @protolabsai/ui catalog ships no sortable primitive, so the interaction is
  implemented inline with native HTML5 drag-and-drop (no new dependency, no bespoke reusable
  DnD component).
