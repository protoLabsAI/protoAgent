- **Scheduler run history API.** `GET /api/scheduler/jobs/{job_id}/runs?limit=N` lists a scheduled job's past runs newest first, each with its slot time, dispatch state, turn outcome and error. It reads the scheduler's existing occurrences ledger (ADR 0135 D8), so there is no second history store; a failed fire now also keeps its error on its own ledger row. Unknown job ids return `404`. Refs #5543.
