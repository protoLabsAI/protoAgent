- **Workflow runs cut off by a restart no longer sit in the history as running forever.** A run record left `running` when the process died was never resumed and never pruned, so `.runs/` grew without bound and the history showed runs as live that had no process behind them (#5411). Starting a run now marks any `running` record that has not been written for 7 days as `failed` with an `interrupted` marker and an explanatory `error`, after which it is pruned under the usual keep-the-newest rule. Paused runs, which wait on an operator, and recently written running runs are left alone.
