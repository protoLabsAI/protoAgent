- **The agent can watch a fleet member's health with no plugin installed.** A built-in `fleet:member_health` check now ships in the same verifier registry plugins contribute to, so `list_verifiers`, the console's check picker and `create_watch` all offer it on a stock install, and a plugin reload keeps it. `create_watch(check="fleet:member_health", check_args={"member": "<id or name>", "state": "down"})` is met when that member is in the requested state (`healthy`, `down` or `wedged`, or a list of them; default `down`); add `on_change` to get a follow-up turn each time the member goes down, wedges or recovers. The check only reads the supervisor's health records (`supervisor.member_health()`), it never probes, and a member with no record (stopped on purpose, not in this fleet, or not checked yet) is not met in any state. Because the registry is no longer empty without a plugin, the watch tools and `set_goal` are bound whenever watches or goal mode are enabled, where they used to wait for a plugin to contribute a check. A plugin cannot replace the built-in by registering the same name. Refs #5534 (ADR 0135 D8).
