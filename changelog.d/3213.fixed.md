- **The console unit suite runs on current Node again (#3213).** Node 24 and newer pre-define the
  Web Storage globals, and vitest's jsdom environment leaves a pre-existing global in place — so
  `localStorage` read `undefined` and 127 of 1325 tests died at `localStorage.clear()` on a clean
  checkout, while `sessionStorage` quietly resolved to Node's implementation rather than jsdom's.
  CI pins Node 20 and never saw it, so the gate looked broken only on contributors' machines. The
  suite now installs jsdom's Storage (and its constructor, which the persist tests spy on) when
  the host Node's is unusable, and `.nvmrc` points humans at CI's Node in the first place.
