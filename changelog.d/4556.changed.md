- **Conversation history moved out of the knowledge store into its own `history` table (#4556).** A one-shot, idempotent boot migration (ADR 0125) drains legacy `domain='conversation'` chunks — compaction archives, retirement summaries and background reports — into the per-agent `history` table in the same `agent.db`, taking an `agent.db.pre-0125` backup first and deleting the moved rows, their FTS entries and their vectors in one transaction. `memory_recall` now returns memory only and points to `session_search` for "what happened"; auto-retrieved context no longer carries history.
