- **Act on a fleet member's turn from the deck (#3470).** A parked question, form, or approval opens as a modal (`enter` on the empty composer, `ctrl+r`) and the answer resumes the parked task the way the console does — approvals `a`/`d`, forms as a stepped wizard with the console's field rules, `ctrl+d` dismisses with the same sentinel so a turn never stays parked. Typing while the member works steers the running turn (queued, folded in at its next model call; `up` takes the newest back; unread ones are re-sent when the turn ends); `ctrl+x` cancels one running `task` delegation. An open conversation marks its session attended, attaches to a server-fired turn there as it runs (and to a turn already in flight when a session is opened), and interjects into it when the member allows. A fleet-wide work feed (`w`) folds every member's event bus — server-fired turns, tool calls, room replies, spend, parks — into one live feed; the roster gains a TURN column and rings the bell when a member newly needs you (parks are tracked per session and merged across the bus, the probe, and the deck's own turns, so the three never overwrite each other). Bus events now carry a `ts` wall-clock stamp so a replaying client shows when things happened, not when it reconnected. Fourth slice of the fleet deck (epic #3466).
