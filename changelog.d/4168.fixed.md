- **The turn-liveness tests no longer flake under CI load (#4168).** The "a step that keeps working outlives the stall window" tests raced a sub-second wall-clock window, so a busy runner could stretch one healthy gap past it and fail an unrelated PR. These tests now measure the window on a virtual clock through a new seam in the A2A stall guard (`a2a_impl.executor._frame_within`). The guard behaves exactly as before.
