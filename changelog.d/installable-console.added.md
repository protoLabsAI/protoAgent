- **Installable console with a push worker.** The console now ships a web manifest (`/app/manifest.webmanifest`: stable app id, start URL `/app/`, standalone display, PNG icons, plus the iOS Home Screen meta tags) and a service worker at `/app/sw.js` scoped to `/app/`. The worker handles `push` and `notificationclick` only: it shows the generic title and body from the versioned payload of ADR 0135 W2, tags each notification with its notice id so a repeat replaces the first, and shows a generic fallback for anything it cannot read. It has no `fetch` handler, never calls the hub, holds no credential and caches nothing; a click focuses or opens a known same-origin console route and ignores any other destination. Both files are served as non-secret static assets with `Cache-Control: no-cache`, and the worker carries its own restrictive Content-Security-Policy. Nothing registers the worker yet. Refs #5539.
