- **Model-role status API.** A read-only `GET /api/config/model-roles` reports, per core model role, the resolved fallback chain (ADR 0133 D2), whether it is set or inherited and from which parent, and the last fallback that fired for it (reason redacted to the exception type/status). For image description it also reports `status: "unavailable"` with `reason: "no-vision"` when no model in its resolved chain — a blank role inherits the main chain — can read images. Feeds the Settings › Models surface.
