- **Demo-agent LLM tools (#4609).** New `fleet_demo_create` / `fleet_demo_configure` / `fleet_demo_chat` / `fleet_demo_delete` / `fleet_demo_list` tools for a managing agent, every op routed through the `demo: true` stamp guard so they can only ever touch throwaway demo members — never a real fleet agent. `fleet_demo_chat` reaches the member's `/api/chat` through the hub's own loopback proxy (the member's scoped token stays server-side and never appears in tool output). Config-gated by `tools.fleet_demo.enabled`, default off.
