- **A coder that fails because its ACP adapter's bundled Claude Code is too old for the model now says how to fix it.** `claude-agent-acp` ships its own Claude Code, so when a new model needs a newer one, every coder on that model fails before doing any work with "Claude Code 2.1.179 does not support this model … Run 'claude update'". That advice updates the wrong binary. The error now keeps the upstream text and adds the real fix: update the adapter (`npm i -g @agentclientprotocol/claude-agent-acp@latest`), or set `CLAUDE_CODE_EXECUTABLE` in the delegate's env to a newer `claude`. The board's block reason and operator notification carry it.
