- **Agent-to-agent addressing could not actually be turned on (#3050).**
  `mention_max_agent_hops` shipped as a dead field. A `LangGraphConfig` attribute is only
  *settable* if `from_dict` reads it, and neither mention knob was read — so no YAML could
  enable the feature, and it had no Settings entry either. The round-trip golden passed
  throughout, because it compares the dataclass field set and never parses a document that
  sets the field.
  Both knobs now load from a `mentions:` section (`max_agent_hops`, `max_per_target`,
  mirroring `goal.max_iterations`) **and** appear in Settings under Behavior → Group chat,
  with `max_per_target` revealed once hops are enabled. The default stays `0` — off is a
  safety property, not an accident.
  The gap is closed with the test the golden couldn't be: parse a doc that *sets* each
  knob and assert it arrives, plus an invariant that every `mentions.*` Settings key round-
  trips through `from_dict` — a Settings control whose key doesn't parse back is a control
  that silently does nothing.
