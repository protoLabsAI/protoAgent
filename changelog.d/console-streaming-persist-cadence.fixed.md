- **The desktop app no longer piles up hundreds of MB of browser-storage log while you chat.** A streaming reply now saves the chat history every ~2s instead of every 300ms. Each save rewrote the agent's whole saved history, and in the desktop app those rewrites piled up in a log file that grew until you quit (204 MB after a 9.5-hour day). The reply on screen still streams live, and a crash mid-reply loses nothing the server can't redraw.
