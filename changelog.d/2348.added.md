- **A running tool card now shows how long it has been running (#2348).** A tool call in
  flight rendered a spinner and nothing else — and a spinner animates identically whether
  the call is doing real work or is wedged, so a fifteen-minute search and a deadlock
  looked exactly the same. Cards that pass ~2s now carry a live elapsed counter
  (`search_files · 15m 04s`) beside the name; a value that keeps climbing is the signal
  that the call is still alive. Quick calls are unchanged.
