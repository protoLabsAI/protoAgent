- **execute_code spills long output to a file instead of dropping it (#3701).** When a script's stdout exceeds `output_truncate`, the head is still returned inline, but the FULL output is now written to a per-session scratch file under the plugin store (`spill/`) and the marker names the absolute path so a follow-up read can recover the rest — evidence sweeps no longer have to re-run with narrower prints. Spill files are capped at 5 MB and pruned after 24h; a failed write falls back to the old truncation marker and never fails the run.
