- **⌘K now clears the chat; the command palette moved to ⌘⇧K (#2949).** The defaults were
  backwards from what chat muscle memory expects: Claude.ai and ChatGPT both put
  clear/new-conversation on ⌘K. The two chords swapped — ⌘K clears the current
  conversation when focus is in the chat panel (identical behavior to `/clear`), ⌘⇧K
  opens the command palette from anywhere. Only the defaults changed: both bindings stay
  user-rebindable in Settings ▸ Keyboard (ADR 0063), and existing overrides keep
  precedence.
