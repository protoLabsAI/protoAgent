- **Telemetry records why a turn failed, and the console shows it (#4733).**
  A failed or canceled turn's row in `turns` used to say only `failed`. It now has an
  `error` column holding the reason: the A2A task's terminal error (including the stall
  guard's message for a wedged turn), the `/v1` error message, or an ACP coder run's
  failure line. The text is redacted and clipped to 500 characters before it is stored, and an incognito turn stores none.
  When a turn is cancelled underneath a stalled turn, the row records the stall guard's
  stop reason instead of a bare "cancelled". Existing stores gain the column on open,
  including pre-#3001 stores that are rebuilt. The Recent turns table shows the reason
  under the state badge, and a tap expands it to the full text, and the background agents dialog now shows a failed job's stored
  error, such as a job interrupted by a server restart. A background job's error is now redacted
  before it is stored, and again when the console reads it, which covers older rows.
