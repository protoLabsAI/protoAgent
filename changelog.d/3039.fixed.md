- **Langfuse host is paired with the layer that supplied the keys** — config can no longer choose the destination for deployment-owned tracing credentials (#3039). `resolve_credentials` resolved the host as `env_host or cfg_host or default` regardless of which layer answered for the keys, and `docker-compose.yml` passes `LANGFUSE_HOST=${LANGFUSE_HOST:-}` — empty for an operator who exports only the key pair — so a `tracing.host` written into `langgraph-config.yaml` (snapshot import, a fork's committed config, any Settings save) sent the deployment's keys, as a Basic auth header, plus span bodies, to a host config named. Env keys now go to `LANGFUSE_HOST`/`LANGFUSE_URL` or the compose default; config keys go to `tracing.host` or the default; neither layer redirects the other's credentials. Snapshot import surfaces `tracing.host` in the plan's capability list alongside `filesystem.allow_run`.
