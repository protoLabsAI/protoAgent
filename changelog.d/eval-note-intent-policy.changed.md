- **The nightly memory evals follow the memory policy.** `memory_note_intent` now asks the agent to note a durable fact ("I'm allergic to penicillin"), which must still be saved to memory. A new case, `memory_status_note_not_saved`, checks that a status note ("my standup just ended…") is NOT saved to memory: since ADR 0125 Phase 3 and v0.233.0, status lines belong in notes, the board or the PR, not in durable memory. The old case expected the opposite, and it began failing on the v0.232.0 nightly run.
