- **Work shows a scheduled job's health and its recent runs.** A job in Coming up whose last runs failed now shows a warning dot and "· failed the last N runs" in its row, and its detail gains a Health field ("Failed the last 3 runs. Last worked …") with the last error. Below the actions, a Recent runs list reads the job's run history newest first: each run says whether it ran, failed, is still running, was skipped or canceled, how long it took and whether it stayed silent, with Show older runs for a longer history. Every time in the detail uses the job's own timezone (UTC when it has none) and names it. Refs #5543.
