- **A streaming A2A peer's delegation card no longer types out the peer's final answer before the chat renders it (#4010).**
  The card was fed the peer's answer artifact, so the reply streamed into the card and then appeared again in the chat. Now the card shows only intermediate work: tool calls, the plan, produced artifacts, and narration that a later tool call proves was intermediate. Delegate text is held until a tool call follows it and dropped when the run ends, so neither an A2A peer nor an ACP coder can flash its answer in the card, and the final `done` snapshot no longer carries it.
