- **Streaming messages gently fade in newly rendered blocks (#2771).** While a message
  is live, each block element that mounts — a new paragraph, list item, table row, the
  footnote section — fades in over 260ms. Pure CSS scoped to the DS's own
  `pl-message--streaming` class: a CSS animation runs once per DOM node lifetime, so
  already-rendered content never re-animates, history and settled messages render
  instantly with no animation, and `prefers-reduced-motion` is respected.
