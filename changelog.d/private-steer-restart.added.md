- **A restart picks private pending turns back up through the private path.** With `private_steering.enabled` on, server start now reloads every conversation that still has a queued, running or parked turn in its private partition, before the scheduler or any steer restart can claim a runner. Queued private turns drain in acceptance order as each recovered turn finishes, carrying only their opaque references, so its text never becomes a peer-readable message. A turn the crash interrupted mid-run is reported as suspended and is not run a second time, and a parked turn stays reserved for its matching resume. A recovery failure is logged, leaves the records as they were and never blocks startup. With the setting off (the default), startup reads and writes nothing for this and behaves as before. Nothing writes private pending turns in normal use yet, so today this only affects records made by tests. Refs ADR 0131.
