- **A helper compacts long command output.** The new `tools.command_output.compact_output` strips ANSI escape codes, keeps only the final state of carriage-return progress redraws, collapses repeated or digits-only-different lines into one line with a repeat count, and keeps a head and tail with one marker naming the dropped line count and the spill file. `write_spill` saves the full output to a unique, size-capped file under the instance data root. It is not yet wired into `run_command`. Refs #5784
