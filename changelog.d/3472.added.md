- **Every hub on the box, from the deck and the CLI (#3472).** `H` in the deck (or `protoagent fleet --all`, with `--json`) lists the hubs this machine runs — the desktop app's, `~/.protoagent`, each scoped instance — and peers found on the network: state, launcher (desktop app / `protoagent up` / foreground), port, version, member counts, instance root. Running hubs come from the heartbeats under every known box root and stopped ones from every instance root with a fleet, never from the shell's `PROTOAGENT_*` environment; a hub that answers but refuses every credential reads `unauthorized`, one that does not answer `unreachable`. `enter` attaches the deck to a hub (its own fleet token), `u` brings a stopped hub up (`protoagent up` for that instance root) and attaches when its port answers; two hubs claiming one port both say so. Sixth slice of the fleet deck (epic #3466).
