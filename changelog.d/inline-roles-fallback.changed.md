- **Role fallbacks for inline workflows.** Goal verification, memory selection, SOUL drift judging, and image description now build their models through role chains, so each falls back to its next entry on a rate limit or other transient error. Single-model settings behave exactly as before. A blank drift-judge or image-description model inherits the main chain (not aux), preserving today's behavior; image description reports itself unavailable when the resolved model can't read images.
