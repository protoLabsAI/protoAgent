- **Role fallbacks for inline workflows.** Goal verification, memory selection, SOUL drift judging, and image description now build their models through role chains, so each falls back to its next entry on a rate limit or other transient error. A blank drift-judge model continues to use main even when aux is configured, and inherits main's fallbacks. Blank image description now inherits the main chain and reports itself unavailable when the resolved model can't read images.
