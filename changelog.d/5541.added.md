- **Unattended turns follow an allow / ask / never approval policy.** A scheduled, watch,
  inbox, webhook, background or goal-driven turn used to answer every approval with a fixed
  "no operator available" text, which always declined it. Now `unattended.allow` runs the
  action, `unattended.ask` parks one decision that shows the tool and its arguments and
  runs it only when you approve, and `unattended.never` (and anything unlisted) is refused
  with a reason the agent can report. Entries are a tool name or `tool:action`. A hub may
  start a local fleet member whose process is dead without asking; nothing else is allowed
  by default. Operator chat turns are unchanged. Settings ▸ Unattended approvals;
  ADR 0124 D5. Refs #5541.
