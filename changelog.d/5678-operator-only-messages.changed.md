- **Decisions: a message from anyone but the operator never answers a paused decision.** A peer agent, a sister agent through the hub (the fleet service token) or a paired agent device that sends a message into a chat with an open decision no longer answers it, even when the message names the paused task, carries the resume flag, or claims to be answered by the operator. The message is held like any other message sent while the decision is open, and the decision stays pending until the operator answers. The operator still answers by message from the console, through the hub, from a paired phone and from a notification tap, and "answered by" always comes from the verified credential, never from the message.
