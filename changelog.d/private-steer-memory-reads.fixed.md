- **Session memory reads respect private steering.** With `private_steering.enabled` on, a conversation that has had a private (human-operator) turn no longer feeds the shared derived memory: its session summary, idle gist and retirement harvest are skipped for that conversation, the way an incognito chat is, and a compaction archive (automatic or `/compact`) still records its ordinary turns while leaving every private turn out. The memory inspector reads (`/api/memory/sessions`, a session's detail, and history search, rollup and entry reads) now apply the same caller check as the chat session reads: a caller that is not a human operator gets 403 "Session read unavailable." for such a session's detail and does not see it in the listings or search results. Human operators, and every conversation without a private turn, see exactly what they did before.
