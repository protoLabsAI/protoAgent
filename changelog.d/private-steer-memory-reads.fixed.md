- **Session memory reads respect private steering.** With `private_steering.enabled` on, a conversation that has had a private (human-operator) turn no longer feeds the shared derived memory: its session summary, idle gist and retirement harvest are skipped for that conversation, the way an incognito chat is, and a compaction archive (automatic or `/compact`) still records its ordinary turns while leaving every private turn out. The memory inspector reads (`/api/memory/sessions`, a session's detail, and history search, rollup and entry reads) now apply the same caller check as the chat session reads: a caller that is not a human operator gets 403 "Session read unavailable." for such a session's detail and does not see it in the listings or search results. Human operators, and every conversation without a private turn, see exactly what they did before. Sessions with private tasks recorded before audience stamps and session markers are also withheld from shared memory; because private turn boundaries cannot be recovered from their unlabelled transcripts, a compaction archive (automatic or `/compact`) keeps the whole transcript in the private partition, which shared history reads never return, so compaction still proceeds and loses nothing. The agent's own `session_search` and `recall_session` tools apply the same check to the caller driving the turn: on a turn that is not a human operator's, such a session is left out of search results and reads as not found. Prompt-side prior-session digests apply the same caller check to recent, relevant and closed-session cards, including legacy cards; cached digests recheck visibility before reuse. When it cannot be read whether a conversation has a private turn, nothing is shared and nothing is discarded: the session summary and gist skip that pass, the retirement harvest fails so the thread is kept for the next sweep, and a compaction archive is kept whole in the private partition, which shared history reads never return.
